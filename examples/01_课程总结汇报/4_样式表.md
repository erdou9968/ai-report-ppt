# 11-10 汇报 PPT 样式表（Claude 2026-11-08）

依据：蒙古答辩 PPT（`Projects\02_Completed\蒙古奶牛项目答辩\02-本人PPT历史版本\20260727-提交版-××修改版.pptx`）的字体、字号、颜色统计，适当调整；颜色换成农大标准绿。不做蒙古 PPT 的深色要点带。
模板：`中国农业大学模板-35.pptx`，只用封面、目录、分隔页、结束页和内容页的校徽；模板里的内容页样式不用。
生成脚本：`build_master.py`（scratchpad，定稿后复制到本文件夹）。

## 颜色
| 用途 | 色值 |
|---|---|
| 主色（标题编号、页眉线、标签底色、面板边线） | 农大绿 `#00873B`（学校官方模板 Grad.02-033 的主题色） |
| 深绿（模板深色部分） | `#006B2F` |
| 浅绿底（原因条、提示框） | `#EAF4EE` |
| 正文 | `#222222` |
| 强调数字 | 深红 `#C00000`（同蒙古 PPT） |
| 图注 | `#595959` |
| 来源 | `#7F7F7F` |

## 版面（16:9，33.87 × 19.05 cm）
- 页眉：标题在左（左边距 0.9 cm），校徽在右上角（高 1.55 cm），2.05 cm 处一条贯通的绿色直线（1.5 磅）。标题不压线。
- 内容区：2.45 cm 到 18.0 cm；左右边距 0.9 cm；面板之间留 0.8 cm。
- 面板：白底圆角矩形，绿色 1.5 磅边线；左上角绿色圆角标签。
- 来源：页底 18.15 cm，一行。
- 图片：按框裁切填满，不拉伸。

## 检查方式
用电脑上的 PowerPoint 把每页导出成 PNG（`render.ps1`），逐页看溢出、重叠、对齐。
