# 两份示例

文件里的路径是我们自己电脑上的，照着改成你的。模板是中国农业大学的，没有放进来，生成脚本里引用的母版要换成你自己的。
写不出来的标准（多密算合适、框怎么摆、话怎么说），看这些文件最快。

## 01_课程总结汇报（8 分钟，19 页，2026-11）

课程学习总结汇报，评委是任课老师。架构改了 9 版，逐页文稿 4 版，PPT 3 版。

| 阶段 | 文件 | 看什么 |
|---|---|---|
| 一、想清楚 | `1_架构定稿.md` | 架构文件长什么样 |
| 二、写内容 | `2_逐页文字稿_终审.md` | 逐页文稿：上屏原文、图片编号、来源、备注 |
| 二、写内容 | `3_联网检索提示词.md` | 按主题分段的检索提示词 |
| 三、做页面 | `4_样式表.md` | 从参照成品统计出来的样式表 |
| 三、做页面 | `脚本/` | `build_master.py`（从学校模板做母版、换标准色）、`build_deck3.py`（逐页生成）、`pptlib.py` |
| 三、做页面 | `第一版与最终版对比.jpg` | 第一版的典型毛病：待放图的占位框、框里大片空白、体会页四个色块卡片 |
| 成品 | `成品总览.jpg` | 最终成品总览，可作视觉参照 |

## 02_课上文献汇报（5 分钟讲＋5 分钟讨论，16 页，2026-11）

课上讲一篇论文，最后两页是讨论问题和讨论小结。PPT 改了 6 版。

| 阶段 | 文件 | 看什么 |
|---|---|---|
| 一、想清楚 | `0_选文标准.md`、`0_精读提示词.md` | 怎么选文献，怎么和联网的 AI 一步一停地精读 |
| 一、想清楚 | `2_v2问题诊断与v3方案.md` | 第二版为什么不对：主角不是论文、为显得丰富往里加东西 |
| 二、写内容 | `1_逐页文稿_v3.md` | 中间版本的逐页文稿；之后的修改直接改在脚本里，定稿文字以 `脚本/build2.py` 为准 |
| 三、做页面 | `脚本/` | `build2.py`（全篇逐页生成，版式变化多，适合照着改）、`pptlib.py` |
| 四、交付 | `3_给其他AI的评审提示词.md` | 找外部意见的写法 |
| 成品 | `成品总览.jpg` | 最终成品 |
