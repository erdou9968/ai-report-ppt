# 防御性写作终审

用途：稿子定稿前做一次全文检查，删掉或改掉“防御性表达”。本文件自成一体，执行方（任何 AI）只需读本文件和稿件。

## 一、任务边界

- **只处理防御性表达。** 不润色，不调结构，不改数据、术语和作者的用词习惯。没问题的句子一个字不动。
- 一篇稿子只审一遍。用户对结果有疑问再单独讨论，不主动复审。
- 不新增数据、引用或分析。拿不准的不自行删，列进“需作者决定”。

## 二、判断标准

只用一条：**删掉这句，读者会不会被实质误导？** 不会，就是防御性表达。

拿不准时再问四个问题：
1. 它在报告有证据支持的条件、不确定性或局限吗？
2. 它的主要目的是回答一个想象中的批评吗？
3. 能改写成“评测了什么／观察到了什么／范围是什么”的正向陈述吗？
4. 同样的限定在别处已经说过了吗？

## 三、常见模式

| 模式 | 信号 | 处理 |
| --- | --- | --- |
| 否认没提过的结论 | “这并不意味着……”“不能据此认定因果”，而正文根本没主张因果 | 删 |
| 罗列没做的事 | 一串“未开展……未测量……未验证……” | 删；真正影响结论的留一条，放局限部分 |
| 同一局限重复 | 结果、讨论、结论各说一遍样本量小 | 只留最合适的一处 |
| 审计式措辞 | “本节仅报告”“不用于判断”“需要强调的是”“为避免误解”“需要指出的是” | 删掉这层壳，直接陈述 |
| 为弱结果开脱 | “虽然提升有限，但仍令人鼓舞”“较低可能是因为……”（无证据） | 先报数据；有证据才解释 |
| 褒义词补证据 | 可靠、鲁棒、有效、优异、令人信服、promising、robust | 换成数据或具体条件 |
| 为选择辩护 | “为了公平比较”“为确保合理” | 直接写控制了什么 |
| 限定堆叠 | “在一定程度上可能有所……”；although/may/only 堆在一个主张周围 | 保留主张，不确定性说一次并说清原因 |
| 空泛收尾 | “这些结果为……奠定了基础”“仍需进一步研究” | 删，或换成有数据支撑的具体推断 |
| 结论自我否定 | 结论最后一段突然列一串不足 | 局限移回局限部分，结论只讲做成了什么 |

**不是见词就删。** 方法部分“未纳入某类样本”可能是必要的研究范围；“横断面设计不能支持因果推断”在讨论里可能是真局限。看它在提供信息，还是在回答没人提的质疑。

## 四、步骤

1. **通读全文**，记两样东西：稿子实际提出了哪些主张；正文里出现的真实局限（样本量、混杂因素、设计限制）及位置。
2. **找可疑句**：含“未、不能、不代表、不用于、仅、尚不能、需要强调、需要注意、值得注意、为了公平、进一步研究、一定程度、可能”及英文 not claim / we emphasize / although / only / may / preliminary / robust / promising 的句子，加上每段末尾的总结句。
3. **逐句判定**：
   - 无问题 → 不动
   - 防御性 → 删除或重写
   - 混合 → 拆开，保留事实，删掉辩解
   - 必要局限 → 保留，必要时换成正向表达，全文只出现一次
4. **跨段检查**：同一局限是否多处出现；摘要或开头几句是否讲清了问题和贡献（只在清单里提，不重写）；结论末段有没有突然自我否定。

## 五、示例

1. 整句删除
   原：该结果仅反映两组受试者菌群内部多样性的差异，尚不能说明具体菌群的变化及其因果关系。
   改：（删除。前文没报告具体菌群，也没提因果。）
2. 并入主张
   原：上述结果只能用于描述，不能据此认定实际代谢活动……（后接一串未开展的测量）
   改：上述结果概括了本研究全体样本的预测功能构成，主要集中于物质运输、营养物质代谢和遗传信息处理等基础生物学过程。（“预测功能构成”已说明边界。）
3. 保留真实局限，换表达
   原：PCoA 结果后接一串“不能证明……”
   改：结合本研究两组 BMI 和腰围差异，PCoA 分布特征提示 NASH 状态与肠道菌群生态差异相关，并可能受到肥胖程度影响。
4. 开脱改数据
   原：Although the improvement is modest, the result remains encouraging given the challenging setting.
   改：Accuracy improves by 0.8 points under the evaluated shift.
5. 公平辩护改事实
   原：为了公平比较，所有方法均使用相同的骨干网络。
   改：所有方法使用相同的骨干网络。

## 六、输出

1. **修订稿**
   - Word 稿：优先输出带修订痕迹（Track Changes）的 .docx，文件名加 `_终审修订`，不覆盖原文件。做不到修订模式时，输出修订后全文另存，并附改动清单。
   - Markdown 或纯文本：修订后全文另存为 `原名_终审修订`。
2. **改动清单**（只列改动的句子）：

   | 位置 | 原句 | 模式 | 处理 | 改后 |
   | --- | --- | --- | --- | --- |

   删除的句子在“改后”栏写“（删除）”。
3. **保留的必要局限**：一行一条，注明位置，供作者确认没删过头。
4. **需作者决定**（最多 3 条）：判断不了是否有证据，或涉及结论表述强弱的地方。

不打分，不写总体评价，不复述全文。

## 七、底线

- 会改变结论的局限、混杂因素和负面结果必须保留。去防御不等于只挑好看的说。
- 不为了“避开弱项”删除或淡化与核心结论有关的结果。
- 课程作业有题目要求的（例如要求写“不足与展望”），按题目要求保留该部分，只去掉其中的空话和重复。
