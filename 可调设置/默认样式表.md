# 默认样式表

这是我们的设计，来自两份成品的统计，可以按自己的偏好和参照成品改。改过的值写回本文件或 `个人偏好.md`，下次直接用。
写进生成脚本时，对应 `scripts/pptlib.py` 开头的样式常量。

| 项 | 默认值 |
|---|---|
| 页面 | 16:9，33.87 × 19.05 cm |
| 字体 | 全篇一种（微软雅黑），中英文和数字都用它 |
| 页面标题 | 28 pt 加粗，编号用主色，页名深灰 #222222 |
| 标题下要点 | 18–20 pt 加粗，一行一条，1–2 条 |
| 正文 | 14–16 pt 加粗（投影上加粗更清楚），不低于 13 pt |
| 面板标签 | 16 pt 加粗，白字主色底，或主色字浅色底 |
| 图注 | 11–12 pt，常规，#595959 |
| 来源 | 10 pt，常规，#7F7F7F，页底居中一行 |
| 页底结论句 | 18–20 pt 加粗，深红，居中 |
| 强调 | 深红 #C00000 加粗，写在句子里，不放大 |
| 主色 | 学校或单位标准色（我们用农大绿 #00873B，深绿 #006B2F，浅绿底 #EAF4EE） |
| 页眉 | 标题在左（左边距 0.9 cm），校徽在右上，下方一条贯通横线（主色 1.5 磅），标题不压线 |
| 内容区 | 上 2.45 cm 到下 18.0 cm，左右边距 0.9 cm，面板间距 0.6–0.8 cm |
| 行距 | 1.1–1.15；段后 2–6 pt；同类条目之间不留大空隙 |
| 面板 | 白底圆角矩形，圆角参数约 0.04，主色线 2.25 磅、带约 30% 透明度；左上角小标签 |

字号单位为磅（pt）。正文全篇加粗是我们的偏好，投影上更清楚；不喜欢可以改成常规。
